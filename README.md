## 📌 Project Overview

This project focuses on replicating the UI/UX architecture, responsiveness, and interactive components of a modern streaming platform. It demonstrates advanced CSS grid/flexbox layouts, custom modal overlays, fluid typography, and multi-stage dynamic form state navigation without relying on heavy frontend frameworks.

### Key Features

* **Authentic UI Design:** Pixel-perfect implementation of Netflix India’s landing page layout, including the hero perspective canvas, custom dynamic carousel sliders, and FAQ accordions.
* **Responsive Multi-Stage Sign-In Funnel:** Seamless state transitions from email input to simulated 4-digit PIN/OTP verification and link completion view.
* **Fully Responsive Layout:** Optimized across mobile handsets, tablets, laptops, and ultra-wide desktop displays using CSS `clamp()` functions and explicit media breakpoints.
* **Accessibility & Performance:** Smooth CSS transitions, semantic HTML structure, keyboard-navigable modals, and lightweight vanilla JavaScript.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup, meta tags, and JSON-LD structured data.
* **CSS3:** Flexbox, CSS Grid, Custom Variables, CSS Animations, and Fluid Typography (`clamp()`).
* **JavaScript (ES6+):** DOM manipulation, multi-stage state management, event listeners, and local storage simulation.
* **FontAwesome 6:** Vector iconography.
